# Таблеточница для Mac

Аналог версии для Windows: те же две вкладки («Сегодня» и «Список и время»),
те же напоминания с кнопками «Принято» / «Через 10 мин» / «Закрыть», импорт CSV,
необязательные дубли в Telegram и на почту. Формат `data.json` тот же, поэтому
данные можно переносить между `Tabletochnitsa.exe` и `Tabletochnitsa.app`.

## Как получить Tabletochnitsa.app (один раз, на Mac)

1. Установите Python с https://www.python.org/downloads/macos/ (3.10 или новее).
   Именно оттуда: в нём свежая версия Tk, на которой построено окно. Python от
   Apple (`/usr/bin/python3`) не подходит — с ним окна работают плохо.
2. Распакуйте эту папку и дважды щёлкните **build_app.command**.
   Если macOS не даёт открыть файл: правый щелчок → «Открыть» → «Открыть».
   Или в Терминале: `cd` в эту папку, затем `bash build_app.command`.
3. Через 1–3 минуты рядом появится **Tabletochnitsa.app**. Его можно перенести
   в «Программы» или на флешку.

Собранное приложение работает на Mac того же типа процессора, на котором его
собрали (Apple M1–M4 или Intel). Чтобы получить одну сборку для обоих, в
`Tabletochnitsa.spec` замените `target_arch=None` на `target_arch='universal2'`
(работает только с Python с python.org).

Если на другом Mac приложение не открывается («не удаётся проверить
разработчика»): правый щелчок → «Открыть», или Системные настройки →
Конфиденциальность и безопасность → «Всё равно открыть». Это нормально для
программ без платной подписи Apple.

## Где хранятся данные

- Если приложение лежит в обычной папке или на флешке — `data.json` рядом с
  `Tabletochnitsa.app` и переезжает вместе с флешкой. Положите `.app` и `.exe`
  в одну папку на флешке — обе программы будут работать с одним списком.
- Если приложение в «Программах» — данные в
  `~/Library/Application Support/Tabletochnitsa/`.

Кнопка «Где мои данные» внизу окна открывает нужную папку в Finder.
Запись идёт через временный файл, поэтому внезапно вынутая флешка не портит
старые данные.

## Что нужно знать

- Напоминания приходят, пока программа запущена. Красная кнопка (или ⌘W)
  сворачивает окно в Dock, напоминания продолжают работать. Полный выход — ⌘Q.
  Вернуть окно — щелчок по значку в Dock.
- В момент приёма появляется окно поверх остальных, звучит сигнал и приходит
  уведомление macOS (его видно и поверх полноэкранных программ). При первом
  уведомлении macOS может спросить разрешение — разрешите.
- Если Mac спал в момент приёма, напоминание придёт сразу после пробуждения
  с пометкой «с опозданием» (в пределах текущих суток).
- Запуск вместе с Mac: Системные настройки → Основные → Объекты входа →
  «+» → выберите Tabletochnitsa.app. С флешки это работает, только если она вставлена.
- ⌘N — добавить пункт.

## Импорт списка из CSV

Кнопка «Импорт CSV…» на вкладке «Список и время». Формат (шаблон — `items.example.csv`):

    name,note,times
    Витамин D,2000 МЕ,08:00
    Аспирин,после еды,08:00;20:00

Подходят и запятые, и «;». В Excel для Mac сохраняйте как «CSV UTF-8».
Файлы из Excel на русской Windows (Windows-1251) тоже читаются.
Повторный импорт не создаёт дубликатов.

## Напоминания в Telegram и на почту (необязательно)

Скопируйте `config.example.json` в `config.json` в папку с данными (или рядом с
`.app`) и заполните:

- Telegram: токен бота от @BotFather и ваш chat_id (его покажет @userinfobot).
  Перед первым использованием напишите своему боту любое сообщение.
- Почта: SMTP-сервер, логин, «пароль приложения» и адрес получателя.

`config.json` содержит пароли, не выкладывайте его.

## Запуск без сборки

`run_without_app.command` запускает программу прямо из `tabletochnitsa.py`
(нужен установленный Python с python.org).
